# File Management System in C++

A simple File Management System built using C++.

## Features
- Create files and folders
- Delete files and folders
- Manage files through a terminal-based menu

## Technologies Used
- C++
- Data Structures and Algorithms (DSA)

## How to Run
Compile the source code using a C++ compiler, then run the generated executable.
